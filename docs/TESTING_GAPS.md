# Testing gaps

Automated unit and component tests cannot prove real GPS accuracy or permission behavior, httpOnly cookie behavior, CORS/`ALLOWED_ORIGIN` configuration, live backend authorization and response compatibility, scanner hardware behavior, Wake Lock behavior, physical phone breakpoints/touch behavior, print output, dark-room visibility at minimum brightness, or behavior during a real power cut. Validate those using `docs/MANUAL_TEST_GUIDE.md` against the backend and devices.
